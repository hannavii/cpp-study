# Study Method

매일 다음 과정을 반복합니다.

1. **Concept** — C++ 핵심 개념 학습
2. **Practice** — 직접 코드 작성 및 실행
3. **Review** — 코드 리뷰와 개선
4. **Troubleshooting** — 오류 원인과 해결 방법 기록
5. **Documentation** — GitHub 학습 기록 작성

코드는 Visual Studio에서 작성하고, 학습 기록은 GitHub의 Markdown 문서로 정리합니다.
