## 2. 비교 연산자

비교 연산자는 두 값을 비교하여 참(`true`) 또는 거짓(`false`)을 반환한다.

| 연산자 | 의미 | 예시 |
|---|---|---|
| `==` | 같다 | `hp == 100` |
| `!=` | 같지 않다 | `hp != 0` |
| `>` | 크다 | `hp > 30` |
| `<` | 작다 | `hp < 30` |
| `>=` | 크거나 같다 | `mp >= 10` |
| `<=` | 작거나 같다 | `hp <= 0` |

`=`는 대입 연산자이고 `==`는 비교 연산자이므로 구분해야 한다.

## 3. 조건문 if / else if / else

`if`문은 조건이 참일 때 특정 코드를 실행한다.

`else if`는 앞선 조건이 거짓일 때 추가 조건을 검사하고, `else`는 모든 앞선 조건이 거짓일 때 실행한다.

```cpp
if (hp <= 0) {
    std::cout << "Dead\n";
}
else if (hp <= 30) {
    std::cout << "Danger\n";
}
else {
    std::cout << "Healthy\n";
}
```

앞선 조건에서 이미 검사한 내용을 다음 조건에서 반복하지 않아도 된다.

## 4. 논리 연산자

여러 조건을 함께 검사할 때 사용한다.

| 연산자 | 의미 |
|---|---|
| `&&` | AND, 양쪽 조건이 모두 참 |
| `\|\|` | OR, 하나 이상의 조건이 참 |
| `!` | NOT, 논릿값 반전 |

```cpp
if (hp >= 1 && hp <= 30) {
    std::cout << "Danger\n";
}
```

HP가 1 이상이고 30 이하인 경우에만 실행된다.

## 5. switch문

`switch`문은 하나의 값을 기준으로 실행할 코드를 선택할 때 사용한다.

```cpp
int menu = 2;

switch (menu) {
case 1:
    std::cout << "Start\n";
    break;
case 2:
    std::cout << "Load\n";
    break;
case 3:
    std::cout << "Exit\n";
    break;
default:
    std::cout << "Invalid\n";
    break;
}
```

- `case`: 값에 따른 실행 경로
- `break`: switch문 종료
- `default`: 일치하는 case가 없을 때 실행

`break`를 생략하면 이후 case의 코드까지 계속 실행될 수 있으므로 주의해야 한다.

## 6. 실습 문제

### 실습 1. HP에 따른 캐릭터 상태 판정

사용자에게 HP를 입력받고 조건에 따라 캐릭터 상태를 출력하였다.

- HP가 0 이하: `Dead`
- HP가 1~30: `Danger`
- HP가 31 이상: `Healthy`

`if`, `else if`, `&&`를 이용하여 구현하였다.

### 실습 2. MP에 따른 스킬 사용 가능 여부

MP를 입력받아 스킬 사용 가능 여부를 출력하였다.

- MP가 10 이상: `Skill Available`
- MP가 10 미만: `Not Enough MP`

두 경우는 서로 반대 조건이므로 `if-else`로 간단하게 구현할 수도 있다.

### 실습 3. 게임 메뉴 선택

`switch`문으로 게임 메뉴를 구현하였다.

| 메뉴 번호 | 출력 |
|---|---|
| 1 | Start |
| 2 | Load |
| 3 | Exit |
| 그 외 | Invalid |

### 실습 4. 몬스터 전투 판정

몬스터의 초기 HP를 100으로 설정하고 입력받은 데미지만큼 체력을 감소시켰다.

```cpp
int mhp = 100;
int dm = 0;

std::cout << "몬스터에게 입힐 데미지를 입력하세요\n";
std::cin >> dm;

mhp -= dm;

if (mhp <= 0) {
    std::cout << "Monster Defeated\n";
}
else {
    std::cout << "Monster Survived: " << mhp << '\n';
}
```

## 7. 코드 리뷰를 통해 배운 점

### 조건의 중복 제거

기존에는 HP가 1 이상이고 30 이하인지 모두 검사했지만, 앞선 `if` 조건을 활용하면 `hp <= 30`만 검사해도 된다.

### else 활용

서로 반대되는 조건을 처리할 때는 불필요한 `else if` 대신 `else`를 사용할 수 있다.

### 입력값 검증의 필요성

몬스터 데미지에 음수를 입력하면 오히려 체력이 증가할 수 있다.

추후 조건문을 활용해 비정상적인 입력을 처리하는 기능을 추가할 수 있다.

### 출력문 작성

`"\n"`과 `'\n'` 모두 줄바꿈에 사용할 수 있다.
