## 2. 난수(Random Number)란?

난수는 쉽게 예측하기 어려운 숫자를 의미한다.

게임에서는 다양한 상황을 구현하기 위해 난수를 활용한다.

| 활용 분야 | 예시 |
|---|---|
| 공격 데미지 | 일정 범위 내 랜덤 데미지 |
| 치명타 | 일정 확률로 공격력 증가 |
| 아이템 드롭 | 확률에 따른 아이템 획득 |
| 몬스터 AI | 공격 패턴 선택 |
| 맵 생성 | 오브젝트의 무작위 배치 |

일반적인 게임 프로그램에서는 알고리즘을 통해 생성하는 의사 난수(Pseudo-Random Number)를 활용한다.

동일한 난수 생성 알고리즘과 초기 상태를 사용하면 동일한 난수 수열을 재현할 수 있다.

## 3. C++ 난수 생성

C++11부터 제공되는 `<random>` 라이브러리를 사용하여 난수를 생성할 수 있다.

### 기본 구조

```cpp
#include <random>

std::random_device rd;
std::mt19937 gen(rd());
std::uniform_int_distribution<int> dist(1, 6);

int num = dist(gen);
```

### random_device

```cpp
std::random_device rd;
```

난수 생성 엔진을 초기화할 때 사용할 값을 얻기 위한 객체이다.

난수 생성 엔진의 초기화에 사용하는 값을 시드(Seed)라고 한다.

### mt19937

```cpp
std::mt19937 gen(rd());
```

메르센 트위스터(Mersenne Twister) 알고리즘을 사용하는 의사 난수 생성 엔진이다.

`rd()`에서 얻은 값을 사용하여 난수 생성 엔진을 초기화한다.

### uniform_int_distribution

```cpp
std::uniform_int_distribution<int> dist(1, 6);
```

지정한 범위의 정수가 균등한 확률로 생성되도록 하는 분포 객체이다.

최솟값과 최댓값을 모두 포함하므로 위 코드에서는 1부터 6까지의 정수가 생성된다.

### 난수 생성

```cpp
int num = dist(gen);
```

난수 생성 엔진을 이용하여 지정된 분포에 맞는 정수 난수를 생성한다.

| 구성 요소 | 역할 |
|---|---|
| `random_device` | 초기화에 사용할 값 제공 |
| `mt19937` | 의사 난수 생성 엔진 |
| `uniform_int_distribution` | 난수의 범위와 확률 분포 설정 |
| `dist(gen)` | 설정된 분포에 따른 난수 생성 |

## 4. 난수와 확률

1부터 100까지의 정수 난수를 생성하면 특정 확률에 따른 조건 분기를 구현할 수 있다.

```cpp
std::uniform_int_distribution<int> attackPer(1, 100);

if (attackPer(gen) <= 20) {
    std::cout << "Critical Hit!\n";
}
else {
    std::cout << "Normal Hit!\n";
}
```

1부터 20까지의 정수가 생성되는 경우 치명타가 발생하므로 치명타 발생 확률은 20%이다.

단, 20% 확률이라고 해서 5번 공격할 때 반드시 한 번 치명타가 발생하는 것은 아니다.

## 5. 실습 문제

### 실습 1. 주사위 굴리기

1부터 6까지의 정수 난수를 생성하고, `for`문을 이용하여 주사위를 총 5번 굴리도록 구현하였다.

```cpp
std::random_device rd;
std::mt19937 gen(rd());
std::uniform_int_distribution<int> dist(1, 6);

for (int i = 0; i < 5; i++) {
    int num = dist(gen);
    std::cout << num << '\n';
}
```

**실행 결과 예시**

```text
3
6
2
2
5
```

**학습 내용**

- 난수 생성 엔진 초기화
- 정수 난수 범위 설정
- 반복문을 활용한 난수 생성
- 난수의 중복 발생 가능성

### 실습 2. 랜덤 데미지

몬스터의 초기 HP를 100으로 설정하고, 10부터 30까지의 랜덤 데미지를 생성하였다.

```cpp
std::uniform_int_distribution<int> dam(10, 30);

int monHp = 100;
int attackDamage = dam(gen);

std::cout << "공격 데미지: " << attackDamage << '\n';
std::cout << "남은 Hp" << monHp - attackDamage << '\n';
```

**실행 결과 예시**

```text
공격 데미지: 25
남은 Hp75
```

**학습 내용**

- 특정 범위의 랜덤 데미지 생성
- 난수를 이용한 체력 계산
- 하나의 난수 생성 엔진에 여러 분포 객체 사용

### 실습 3. 치명타 시스템

기본 공격력을 20으로 설정하고, 20% 확률로 치명타가 발생하도록 구현하였다.

치명타가 발생하면 공격력이 두 배가 된다.

```cpp
int normalAttack = 20;
std::string attackPower = "Normal Hit";

std::uniform_int_distribution<int> attackPer(1, 100);

if (attackPer(gen) <= 20) {
    normalAttack *= 2;
    attackPower = "Critical Hit";
}

std::cout << "공격 종류: " << attackPower << '\n';
std::cout << "데미지: " << normalAttack << '\n';
```

**일반 공격 결과**

```text
공격 종류: Normal Hit
데미지: 20
```

**치명타 공격 결과**

```text
공격 종류: Critical Hit
데미지: 40
```

**학습 내용**

- 확률 기반 조건 분기
- `*=` 복합 대입 연산자
- 문자열 변수를 이용한 공격 종류 관리
- 조건문과 난수 생성의 결합

### 실습 4. 랜덤 턴제 전투

몬스터의 HP가 0 이하가 될 때까지 10~30 사이의 랜덤 데미지로 자동 공격하도록 구현하였다.

매 공격마다 남은 HP를 출력하고, 전투 종료 후 총 공격 횟수를 출력하였다.

```cpp
int a = 0;

while (monHp > 0) {
    attackDamage = dam(gen);
    monHp -= attackDamage;

    std::cout << "공격 데미지: " << attackDamage << '\n';
    std::cout << "남은 HP" << monHp << '\n';

    a += 1;
}

std::cout << "총 공격횟수: " << a << '\n';
std::cout << "Monster Defeat!\n";
```

**실행 결과 예시**

```text
공격 데미지: 25
남은 HP75
공격 데미지: 30
남은 HP45
공격 데미지: 20
남은 HP25
공격 데미지: 28
남은 HP-3
총 공격횟수: 4
Monster Defeat!
```

**학습 내용**

- `while`문을 이용한 자동 전투
- 매 반복마다 새로운 랜덤 데미지 생성
- 복합 대입 연산자를 이용한 HP 감소
- 공격 횟수 저장 및 증가
- 몬스터의 체력에 따른 전투 종료

## 6. Troubleshooting

### 1. 세미콜론 누락

**오류 코드**

```cpp
int a = 0

while (monHp > 0) {
    // 전투 로직
}
```

변수 선언문의 끝에 세미콜론이 없어 컴파일 오류가 발생하였다.

실제 오류는 변수 선언 부분에 있지만, Visual Studio에서는 다음 줄인 `while`문에 오류가 표시되었다.

**수정 코드**

```cpp
int a = 0;
```

특정 줄에서 문법 오류가 발생하면 해당 줄뿐 아니라 이전 줄의 문법도 확인해야 한다.

### 2. 변수 선언과 값 변경의 혼동

**오류 코드**

```cpp
int a += 1;
```

이미 선언한 변수의 값을 증가시키는 과정에서 자료형을 다시 작성하여 컴파일 오류가 발생하였다.

**수정 코드**

```cpp
a += 1;
```

기존 변수의 값을 증가시킬 때는 다음과 같은 표현을 사용할 수 있다.

```cpp
a += 1;
a++;
++a;
```

각 표현은 독립적으로 사용했을 때 변수의 값을 1 증가시킨다.

### 3. while문 조건 오류

**기존 코드**

```cpp
while (monHp <= 0) {
    // 전투 로직
}
```

몬스터의 초기 HP가 100이므로 조건이 처음부터 거짓이 되어 전투가 실행되지 않는다.

**수정 코드**

```cpp
while (monHp > 0) {
    // 전투 로직
}
```

`while`문에는 반복을 종료할 조건이 아니라 반복을 계속할 조건을 작성해야 한다.

몬스터가 살아 있는 동안 공격을 반복하고, HP가 0 이하가 되면 전투를 종료하도록 수정하였다.

### 4. 문자열 헤더 추가

`std::string`을 사용하기 위해 다음 헤더를 명시적으로 추가하였다.

```cpp
#include <string>
```

표준 라이브러리 기능을 사용할 때 해당 기능을 제공하는 헤더를 직접 포함하는 습관이 중요하다.

## 7. 코드 리뷰 및 개선 사항

### 1. 계산과 대입의 차이

```cpp
monHp - attackDamage;
```

위 표현식은 계산 결과를 생성하지만 기존 변수의 값은 변경하지 않는다.

```cpp
monHp -= attackDamage;
```

위 표현식은 계산 결과를 기존 변수에 저장하므로 실제 HP가 감소한다.

실습 2에서는 남은 HP의 계산 결과만 출력하였으며, 실습 4에서는 실제 HP 변수의 값을 변경하였다.

### 2. 난수 생성 엔진 재사용

```cpp
std::random_device rd;
std::mt19937 gen(rd());

std::uniform_int_distribution<int> dist(1, 6);
std::uniform_int_distribution<int> dam(10, 30);
std::uniform_int_distribution<int> attackPer(1, 100);
```

하나의 난수 생성 엔진을 초기화하고, 목적에 따라 서로 다른 분포 객체를 사용하였다.

난수를 생성할 때마다 엔진을 다시 초기화할 필요는 없다.

### 3. 변수명 개선

현재 공격 횟수를 저장하는 변수의 이름은 `a`이다.

```cpp
int a = 0;
```

추후에는 변수의 역할을 명확하게 나타내도록 다음과 같은 이름을 사용할 수 있다.

```cpp
int attackCount = 0;
```

### 4. HP 최솟값 처리

현재 구현에서는 몬스터의 남은 체력보다 큰 데미지가 발생하면 HP가 음수로 출력될 수 있다.

전투 종료 조건에는 문제가 없지만, 실제 게임 시스템에서는 HP의 최솟값을 0으로 제한하도록 개선할 수 있다.

이번 실습에서는 기존 코드를 유지하고 개선 사항만 기록하였다.
