# Day 11 — Pointers

## 1. 학습 목표

C++의 포인터(Pointer)를 학습하고, 메모리 주소를 이용하여 변수에 접근하고 값을 변경하는 방법을 익혔습니다.

DAY 10에서 학습한 참조자(Reference)와 비교하면서 포인터의 특징을 이해하고, `nullptr` 검사를 통해 잘못된 메모리 접근을 방지하는 기초적인 방법을 실습했습니다.

**주요 학습 내용**
- 포인터의 개념과 선언 방법
- 주소 연산자 `&`
- 역참조 연산자 `*`
- 포인터를 이용한 원본 변수 수정
- 포인터가 가리키는 대상 변경
- `nullptr`의 의미와 검사 방법
- 포인터를 함수의 매개변수로 전달하기
- 참조자와 포인터의 차이

## 2. 핵심 개념

### 2.1 포인터(Pointer)란?

포인터는 다른 객체의 메모리 주소를 저장하는 변수입니다.

```cpp
int hp = 100;
int* ptr = &hp;
```

각 표현의 의미는 다음과 같습니다.

| 표현 | 의미 |
|---|---|
| `hp` | 변수에 저장된 값 |
| `&hp` | 변수 `hp`의 메모리 주소 |
| `int* ptr` | 정수형 포인터 변수 선언 |
| `ptr` | 포인터에 저장된 주소 |
| `*ptr` | 포인터가 가리키는 객체의 값 |

`ptr`에는 `hp`의 주소가 저장되므로, `*ptr`을 사용하면 `hp`의 값에 접근할 수 있습니다.

### 2.2 주소 연산자 `&`

주소 연산자 `&`를 사용하면 변수의 메모리 주소를 얻을 수 있습니다.

```cpp
int hp = 100;

std::cout << &hp << '\n';
```

메모리 주소는 일반적으로 다음과 같은 형태로 출력됩니다.

```text
0x000000A12F
```

실제 주소는 실행 환경과 실행 시점에 따라 달라질 수 있습니다.

### 2.3 역참조 연산자 `*`

포인터를 역참조하면 포인터가 가리키는 객체에 접근할 수 있습니다.

```cpp
int hp = 100;
int* ptr = &hp;

std::cout << *ptr << '\n';
```

출력 결과:

```text
100
```

역참조는 값을 읽는 것뿐 아니라 원본 객체를 수정할 때도 사용할 수 있습니다.

```cpp
*ptr = 60;
```

이 코드를 실행하면 `hp`의 값이 60으로 변경됩니다.

### 2.4 ptr과 *ptr의 차이

이번 실습에서 가장 중요하게 학습한 부분입니다.

```cpp
int hp = 100;
int* ptr = &hp;
```

**포인터가 가리키는 값 변경**

```cpp
*ptr = 60;
```

- `hp`의 값이 60으로 변경됩니다.
- `ptr`에 저장된 주소는 변경되지 않습니다.

**포인터가 가리키는 대상 변경**

```cpp
int a = 50;
ptr = &a;
```

- `ptr`에 저장된 주소가 `a`의 주소로 변경됩니다.
- 이후 `*ptr`은 `a`를 나타냅니다.
- 기존 변수 `hp`의 값은 변경되지 않습니다.

즉, `ptr`에 대입하면 포인터에 저장된 주소가 변경되고, `*ptr`에 대입하면 포인터가 가리키는 객체의 값이 변경됩니다.

### 2.5 nullptr

`nullptr`은 포인터가 아무 객체도 가리키지 않음을 나타내는 널 포인터 값입니다.

```cpp
int* ptr = nullptr;
```

널 포인터를 역참조하면 정의되지 않은 동작(Undefined Behavior)이 발생합니다.

따라서 역참조하기 전에 `nullptr` 여부를 검사할 수 있습니다.

```cpp
if (ptr == nullptr) {
    std::cout << "Pointer is null" << '\n';
}
else {
    std::cout << "Pointer Value: " << *ptr << '\n';
}
```

단, `nullptr` 검사는 포인터가 널 포인터인지만 확인합니다. 널 포인터가 아닌 모든 포인터가 반드시 유효한 것은 아닙니다.

## 3. 실습 문제

### 실습 1. 변수 주소와 포인터 출력

**문제**

정수형 변수 `hp`를 선언하고, 해당 변수의 주소를 포인터에 저장한 뒤 다음 항목을 출력합니다.

- HP 값
- HP의 메모리 주소
- 포인터에 저장된 주소
- 포인터가 가리키는 값

**작성 코드**

```cpp
int hp = 100;
int* ptr = &hp;

std::cout << "HP: " << hp << '\n';
std::cout << "HP Address: " << &hp << '\n';
std::cout << "Pointer Address Value: " << ptr << '\n';
std::cout << "Pointer Value: " << *ptr << '\n';
```

**예상 출력 예시**

```text
HP: 100
HP Address: 0x1000
Pointer Address Value: 0x1000
Pointer Value: 100
```

주소 `0x1000`은 설명을 위한 예시입니다.

**학습 내용**

`&hp`와 `ptr`이 같은 주소를 나타낸다는 것을 확인했습니다.

또한 `ptr`은 주소를 저장하지만, `*ptr`은 해당 주소에 있는 객체의 값에 접근한다는 차이를 학습했습니다.

### 실습 2. 포인터를 이용한 HP 변경

**문제**

포인터를 이용하여 플레이어의 HP를 100에서 60으로 변경합니다.

**작성 코드**

```cpp
*ptr = 60;
std::cout << "Player HP: " << hp << '\n';
```

**출력 결과**

```text
Player HP: 60
```

**학습 내용**

`*ptr = 60`을 실행하면 포인터 자체가 아니라 포인터가 가리키는 원본 변수 `hp`의 값이 변경됩니다.

따라서 `hp`를 직접 출력해도 60이 출력됩니다.

### 실습 3. nullptr 검사

**문제**

- 기존 포인터에 `nullptr` 대입
- 널 포인터 여부 검사
- `hp`에 80 저장
- 포인터가 다시 `hp`를 가리키도록 변경
- 변경된 포인터를 검사하고 값 출력

**작성 코드**

```cpp
ptr = nullptr;

if (ptr == nullptr) {
    std::cout << "Pointer is null" << '\n';
}
else {
    std::cout << "Pointer Value: " << *ptr << '\n';
}

hp = 80;
ptr = &hp;

if (ptr == nullptr) {
    std::cout << "Pointer is null" << '\n';
}
else {
    std::cout << "Pointer Value: " << *ptr << '\n';
}
```

**출력 결과**

```text
Pointer is null
Pointer Value: 80
```

**학습 내용**

포인터가 `nullptr`인 경우에는 역참조하지 않도록 조건문을 작성했습니다.

이후 `ptr = &hp`를 실행하여 포인터가 다시 `hp`를 가리키도록 변경했습니다.

포인터에 저장된 주소는 변경할 수 있으며, 기존 포인터를 재사용할 때는 자료형을 다시 선언하지 않는다는 점도 학습했습니다.

### 실습 4. 포인터를 이용한 공격 함수

**문제**

- 초기 플레이어 HP: 100
- 몬스터 공격력: 35
- 포인터를 함수의 매개변수로 전달
- 함수 내부에서 `nullptr` 검사
- 원본 HP 감소
- `return` 없이 HP 변경

**작성 코드**

```cpp
void takeDamage(int* hp, int damage) {
    if (hp == nullptr) {
        std::cout << "Pointer is null" << '\n';
    }
    else {
        *hp -= damage;
    }
}
```

**함수 호출**

```cpp
int MonDm = 35;
hp = 100;

std::cout << "Before Damage: " << hp << '\n';

takeDamage(&hp, MonDm);

std::cout << "After Damage: " << *ptr << '\n';
```

**출력 결과**

```text
Before Damage: 100
After Damage: 65
```

이 코드는 앞선 실습에서 `ptr = &hp`로 설정한 상태를 이어서 사용합니다.

**학습 내용**

`takeDamage()` 함수에 `hp`의 메모리 주소를 전달했습니다.

함수 내부에서는 포인터가 `nullptr`이 아닌 경우에만 역참조하여 원본 HP를 변경했습니다.

DAY 10에서는 참조자를 사용하여 원본 값을 변경했지만, 이번 실습에서는 포인터를 이용하여 같은 기능을 구현했습니다.

## 4. 개발 과정에서 발생한 오류와 해결

### 4.1 포인터 중복 선언 오류

**문제**

실습 1에서 선언한 포인터를 실습 3에서 다시 선언하여 컴파일 오류가 발생했습니다.

```cpp
int* ptr = &hp;

// 동일한 범위에서 다시 선언
int* ptr = nullptr;
```

**원인**

같은 유효 범위(Scope)에서 동일한 이름의 지역 변수를 중복 선언할 수 없기 때문입니다.

**해결**

이미 선언된 포인터를 재사용할 때는 자료형을 다시 작성하지 않고 새로운 값을 대입했습니다.

```cpp
ptr = nullptr;
```

**배운 점**

- `int* ptr = &hp;`: 새로운 포인터 변수 선언 및 초기화
- `ptr = nullptr;`: 기존 포인터에 널 포인터 값 대입
- `ptr = &hp;`: 기존 포인터에 변수의 주소 대입

### 4.2 대입 연산자와 비교 연산자 혼동

**문제**

처음에는 널 포인터 검사 조건을 다음과 같이 작성했습니다.

```cpp
if (ptr = nullptr)
```

**원인**

`=`는 대입 연산자이며, `==`는 비교 연산자입니다.

포인터가 `nullptr`인지 검사해야 하는데, 대입 연산자를 사용하여 포인터 값을 변경하려고 했습니다.

**해결**

```cpp
if (ptr == nullptr)
```

**배운 점**

조건문에서 포인터의 상태를 검사할 때는 대입과 비교를 구분해야 합니다.

### 4.3 nullptr 검사의 위치

**문제**

처음에는 `main()`에서 포인터를 검사했지만, 실제로 포인터를 역참조하는 함수 내부에는 검사를 작성하지 않았습니다.

```cpp
void takeDamage(int* hp, int damage) {
    *hp -= damage;
}
```

이 상태에서 `nullptr`을 전달하면 잘못된 역참조가 발생할 수 있습니다.

**해결**

함수 내부에서 전달받은 포인터를 먼저 검사하도록 수정했습니다.

```cpp
void takeDamage(int* hp, int damage) {
    if (hp == nullptr) {
        std::cout << "Pointer is null" << '\n';
    }
    else {
        *hp -= damage;
    }
}
```

**배운 점**

포인터를 역참조하는 코드에서 해당 포인터의 유효성을 고려해야 합니다.

이번 실습에서는 함수 내부에서 `nullptr` 여부를 검사하여 널 포인터 역참조를 방지했습니다.

## 5. DAY 10과 비교 — 참조자와 포인터

DAY 10에서는 참조자(Reference)를 이용하여 HP를 변경했습니다.

```cpp
void takeDamage(int& hp, int damage) {
    hp -= damage;
}
```

함수 호출:

```cpp
takeDamage(hp, 35);
```

DAY 11에서는 포인터(Pointer)를 이용하여 동일한 기능을 구현했습니다.

```cpp
void takeDamage(int* hp, int damage) {
    if (hp != nullptr) {
        *hp -= damage;
    }
}
```

함수 호출:

```cpp
takeDamage(&hp, 35);
```

**비교**

| 구분 | 참조자 | 포인터 |
|---|---|---|
| 매개변수 | `int& hp` | `int* hp` |
| 함수에 전달 | `hp` | `&hp` |
| 원본 값 변경 | `hp -= damage` | `*hp -= damage` |
| 가리키는 대상 변경 | 불가능 | 가능 |
| nullptr 사용 | 일반적인 참조자에는 사용하지 않음 | 가능 |
| 원본 수정 | 가능 | 가능 |

참조자는 기존 객체의 다른 이름으로 사용하며, 포인터는 주소를 저장하고 필요에 따라 다른 객체를 가리키도록 변경할 수 있습니다.

## 6. 이번 실습에서 배운 점

### 6.1 포인터 자체와 포인터가 가리키는 값은 다르다

`ptr`과 `*ptr`의 차이를 이해했습니다.

- `ptr`을 변경하면 포인터에 저장된 주소가 바뀝니다.
- `*ptr`을 변경하면 포인터가 가리키는 객체의 값이 바뀝니다.

### 6.2 포인터는 가리키는 대상을 변경할 수 있다

기존 포인터에 `nullptr`이나 다른 변수의 주소를 대입할 수 있다는 것을 학습했습니다.

이 과정에서 포인터의 선언과 재대입을 구분하는 방법을 익혔습니다.

### 6.3 포인터 역참조 전에는 안전성을 고려해야 한다

`nullptr`을 역참조하면 정의되지 않은 동작이 발생합니다.

이번 실습에서는 함수 내부에 널 포인터 검사를 추가하여 해당 상황을 방지했습니다.

### 6.4 포인터를 이용하여 함수에서 원본 값을 수정할 수 있다

함수에 변수의 주소를 전달하고, 함수 내부에서 역참조하여 원본 값을 변경했습니다.

이를 통해 DAY 09의 반환값 방식, DAY 10의 참조자 방식, DAY 11의 포인터 방식을 비교할 수 있었습니다.
