
# Day 01 - Hello C++!

## 학습 내용
- C++ 프로그램의 기본 구조
- main() 함수
- std::cout을 이용한 출력
- << 연산자의 역할
- \n과 std::endl의 차이
- 출력 버퍼와 flush의 개념
- int 변수 선언과 값 변경

## 핵심 정리

### 1. std::cout
표준 출력 스트림 객체이다.
Java의 System.out.print()와 비슷하다.

### 2. << 연산자
데이터를 출력 스트림에 삽입한다.

### 3. \n과 std::endl
- \n: 줄바꿈 문자
- std::endl: 줄바꿈 후 flush 수행

### 4. Flush
출력 버퍼의 데이터를 실제 출력 대상으로
전달하도록 요청하는 동작이다.

버퍼링은 여러 출력 작업을 효율적으로
처리하는 데 도움을 준다.

## 오늘의 실습
캐릭터의 체력과 공격력을 변수로 선언하고,
피해를 받은 후 체력이 감소하도록 구현했다.

## 배운 점
C++의 출력 방식과 버퍼링 개념을 이해했다.
변수를 사용해 게임 데이터를 표현하는
간단한 프로그램을 작성했다.
